## Codebase Patterns
- Project root is ship-or-skip/, lib files are in src/lib/
- Use .env.local for local secrets, .env.example for documented templates
- .gitignore uses `.env*` but allows `!.env.example`
- TypeScript strict mode, run `npx tsc --noEmit` to check
- Delete `.next` folder if stale build errors occur during typecheck
- Data sources go in src/lib/data-sources/, use barrel exports (index.ts)
- OpenAI: use gpt-4o-mini with `response_format: { type: 'json_object' }` for structured extraction
- Color scheme uses CSS variables in globals.css: use text-foreground-secondary (not /60), border-border, bg-surface, bg-button-bg, text-button-text, focus:ring-focus-ring
