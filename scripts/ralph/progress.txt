## 2026-01-16 - US-011
- Implemented: Created similarity matching algorithm in src/lib/similarity.ts
- Files changed:
  - `ship-or-skip/src/lib/similarity.ts` - New similarity module with findSimilarCompanies function
- **Learnings for future iterations:**
  - Tokenization: lowercase -> remove punctuation -> split on whitespace -> filter stop words
  - Stop words defined as Set for O(1) lookup: the, for, and, that, with, your, a, an, to, of, is, in, on
  - Similarity formula: matching tokens / user tokens (returns 0-100 percentage)
  - Filter threshold: > 0.2 (20%) to avoid noise from common words
  - Returns top 10 matches sorted by score descending
  - Exported types: SimilarityCompany (input), SimilarCompanyResult (output with score)
  - Uses SourceOutcome type from supabase/types.ts for consistency
