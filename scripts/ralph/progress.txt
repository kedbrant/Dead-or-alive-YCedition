## Codebase Patterns
- Use Tailwind classes for styling: `bg-surface`, `text-foreground`, `text-ship` (green), `text-skip` (red)
- Color scheme: purple-400/500 for accents, ship (green #22C55E), skip (red #EF4444)
- Form inputs use `bg-surface border border-foreground/20 rounded-xl`
- Buttons use hover effects: `hover:shadow-[0_0_20px_rgba(34,197,94,0.5)] hover:scale-[1.02]`
- Missing dependencies may exist in node_modules but not package.json (clsx, tailwind-merge, motion)
- API routes: Use `NextRequest`/`NextResponse`, import `createServerSupabaseClient` from `@/lib/supabase/server`
- Database types: All table types defined in `@/lib/supabase/types.ts`, export Row/Insert/Update variants
- Data source modules: Place external data fetching in `/lib/data-sources/` (e.g., yc.ts, news.ts, reddit.ts)
- AI modules: Place AI/ML integrations in `/lib/ai/` (e.g., openai.ts)
- OpenAI: Use `response_format: { type: 'json_object' }` for structured output, always provide fallback
- Migrations: Use `IF NOT EXISTS` for idempotent migrations, naming: `NNN_descriptive_name.sql`
- Use `JSONB` not `JSON` for flexible structured data storage in Postgres
