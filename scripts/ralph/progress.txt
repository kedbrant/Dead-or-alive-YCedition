## Codebase Patterns
- Next.js 16+ uses Tailwind v4 with `@theme inline` in globals.css for custom colors
- Use `--color-*` CSS variables in @theme block for Tailwind utility class support
- Inter font loaded via `next/font/google` with `variable: "--font-inter"`
- Dark theme enforced via `className="dark"` on html element
- Supabase clients: `client.ts` for browser, `server.ts` for server-side with service role key
- TypeScript types in `lib/supabase/types.ts` - import `Database` for createClient generic
- **CRITICAL:** Supabase Database type MUST include `Relationships: []` in each table and `CompositeTypes` in schema for proper type inference
- API routes use `.limit(1).returns<Type[]>()` instead of `.single()` for single record fetches to avoid `never` type issues
- For Supabase write operations, use explicitly typed variables (e.g., `const insert: VoteInsert = {...}`)
- SQL migrations in `supabase/migrations/` numbered 001_, 002_, etc.
- Components organized in `src/components/` by feature (e.g., `voting/`, `submit/`, `layout/`)
- Session management: `lib/session/manager.ts` with `getOrCreateSessionId()` for server components
- Seed scripts: `npx tsx scripts/seed-*.ts` - use dotenv to load .env.local, batch upserts for performance
- YC data source: YC-OSS API at `https://yc-oss.github.io/api/companies/all.json` for public YC company data
- Swipe gestures: SwipeContainer component uses native touch/mouse events with 100px threshold, card tilt, and elastic rubber-band cancel animation
- OG meta tags: Default in layout.tsx with metadataBase, dynamic via generateMetadata() in pages, dynamic OG images via /api/og edge endpoint
- YC API endpoint: https://yc-oss.github.io/api/companies/all.json
- YC company status values: 'Public', 'Active', 'Inactive', 'Acquired'
- Source outcome mapping: top_company=true OR status='Public' -> 'unicorn', status='Acquired' -> 'acquired', status='Inactive' -> 'dead', else -> 'active'
- Active pool: is_in_active_pool=true marks companies that appear in voting rotation
